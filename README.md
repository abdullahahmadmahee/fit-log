# FitLog - Workout Library

FitLog is a dark, no-nonsense gym companion app that allows users to browse a dynamic workout library, view detailed exercise instructions, and curate their own daily training plans. Built for Assignment 6 by Abdullah Ahmad Mahee.

## Technologies Used
- Next.js (App Router)
- React.js
- Tailwind CSS
- Context API (State Management)
- LocalStorage (Data Persistence)

## 5 Key Features
1. Dynamic Workout Library:** Fetches live exercise data from an external REST API and displays it in a responsive grid.
2. Interactive Planning:** Users can add workouts to "Today's Plan" (capped at 5 exercises) or "Save for Later".
3. Real-Time Metrics:** Automatically calculates total exercises, combined duration, and total calories burned based on the current plan.
4. Data Persistence:** Utilizes LocalStorage to ensure the user's saved plans and workouts survive page reloads.
5. Advanced Sorting & Tracking:** Users can sort their saved lists by Duration, Calories, or Rating, and mark individual exercises as "Done" with instant visual feedback.
